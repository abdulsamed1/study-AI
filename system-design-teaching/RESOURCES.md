# System Design Resources

## Knowledge

- [System Design Primer — Donneke](https://github.com/donnemartin/system-design-primer)
  The definitive free resource. Covers fundamentals through advanced with diagrams and flashcards. Use for: everything — this is the backbone of the curriculum.
- [Grokking the System Design Interview — Educative](https://www.educative.io/courses/grokking-the-system-design-interview)
  Pattern-based approach to common interview questions. Use for: interview prep and seeing how concepts compose into real designs.
- [High Scalability](http://highscalability.com/)
  Real-world architecture case studies (Instagram, WhatsApp, Twitter). Use for: understanding how production systems handle scale.
- [Martin Kleppmann — Designing Data-Intensive Applications](https://dataintensive.net/)
  Deep treatment of storage, replication, partitioning, transactions. Use for: understanding database internals and distributed data.
- [Netflix Tech Blog](https://netflixtechblog.com/)
  Real engineering blog from a massive-scale system. Use for: seeing how concepts like caching, CDNs, and microservices work in production.
- [AWS Architecture Center](https://aws.amazon.com/architecture/)
  Official patterns and reference architectures. Use for: understanding cloud-native design patterns.

## Wisdom (Communities)

- [r/systemdesign](https://reddit.com/r/systemdesign)
  Active subreddit for system design interview prep and architecture discussions. Use for: practice questions, feedback on designs, learning from others' mistakes.
- [Hacker News](https://news.ycombinator.com/)
  High-signal tech community. Use for: staying current on architecture trends and real-world war stories.
- Local: Eagles project — a live production system to study and ask "why was this designed this way?"

## Gaps

- No single resource covers blockchain-specific system design well. Will supplement with domain knowledge from the user's blockchain background when relevant (e.g., distributed ledgers, consensus, on-chain vs off-chain).
- Lessons are in English only, in simple English for the learner (level B1/B2); confirmed by the user 2026-10-21.
