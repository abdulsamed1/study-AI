# Mission: Become a hireable Frontier Deployed Engineer (FDE)

*Draft 2026-10-09. Confirm or edit in the first session; the mentor must not change it without asking.*

## Why

Get hired as an FDE by being able to show one real, evaluated, secured, deployed, and handed-over agentic system, and by being able to defend every design decision in it. The role standard is in `AGENTS.md` section 1.

## Success looks like

- I can take an ambiguous business problem, decide whether AI is the right tool (and say "no" when it is not), and justify the level of autonomy.
- I have a repository for one capstone system with tests, an evaluation set (including adversarial cases), tracing, a security review, a deployment, and a runbook.
- I can produce and defend these artifacts: Architecture Decision Records, a Threat Model, an Evaluation Report, a Runbook.
- I can diagnose a production incident from evidence (using the performance map) and explain what I have and have not done, truthfully, in English.

## Constraints

- I do not edit project files by hand: in ChatGPT Project, progress lives in the Project's own memory (see `AGENTS.md` section 2). Writing code by hand as a learning exercise is a separate decision, made per lesson under the journey's hand-writing versus review rule.
- Explanations in English only, in simple English (my level: B1/B2) — short sentences, plain words, define each technical term on first use. No Arabic anywhere: not in files, sessions, lessons, or logs. Technical terms and code stay in English.
- current baseline: set in session 1.

## Out of scope

- Training foundation models; ML research and math unless a deployed system needs it (basic statistics for evaluation is in scope).
- Pure prompt engineering as a goal; demos with no path to production.
